Основание: «Методические указания к Проектной работе по дисциплине
„Интеллектуальный анализ данных“», предоставленные в PDF. Этот документ
фиксирует требования к результату проекта, а не команды для инструментов.

## Компоненты по выбору

В задании они выделены отдельной группой (30 баллов суммарно). Число
компонентов для конкретного профиля нужно уточнить у преподавателя.
Предлагаемый основной вариант — автоматизированный подбор моделей и журнал
экспериментов: временной поиск гиперпараметров, MLflow, версия данных,
воспроизведение по run ID, отдельный holdout, сравнение в интерфейсе.

Расширения после основной части: permutation importance и SHAP; мониторинг
дрейфа, отложенной ошибки, правила переобучения и отката. До реализации они
не считаются выполненными.

## Постановка задачи

- Регион: США, Флорида; река Suwannee, пост Branford, USGS `02320500`.
- Цель: уровень воды в сантиметрах относительно нуля **одного и того же**
  гидропоста, горизонт один календарный день.
- Цель определена однозначно: суточный средний уровень USGS `00065 / 00003`;
  максимумы и мгновенные значения не подменяют среднее.
- Пользователь: аналитик, наблюдающий динамику выбранного участка реки.
- Решение: увидеть ожидаемое изменение уровня, ошибку модели и свежесть
  наблюдений. Опасные отметки добавляются только с проверенным источником.
- Метрики на синтетике проверяют работоспособность кода и не доказывают
  качество прогноза для реальной реки.
