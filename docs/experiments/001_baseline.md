# Эксперимент 001: исходный persistence baseline

Дата: 1 ноября 2026 года. Этап: основа проекта до обучения моделей.

## Данные и настройки

- Пост: **Suwannee River at Branford, Florida, USGS 02320500**.
- Гидрология: USGS Water Data API v1, коллекция `daily`.
- Цель: суточный средний уровень, `00065 / 00003`, футы переведены в см.
- Расход: `00060 / 00003`, переведён в м³/s и сохранён в дневной таблице.
- Погода: Open-Meteo ERA5, температура, осадки, влажность, фиксированный EST.
- Общий период: 2008–2023, 5 844 календарных дня.
- Пропуски: уровень — 107, расход — 1, погодные переменные — 0.
- Один суточный скачок уровня больше 100 см по модулю сохранён для анализа.
- SHA-256 дневного CSV:
  `188d8197d4b952b9dd6c458dab5ecac22d35e713dfb5644957ea85f42491e378`.

2023 год исключён из текущих метрик. Период разработки — 2008–2022;
последние 20% его календарных дат дают оценочный период 2020–2022.

## Метод и результат

Для каждого origin `t` прогноз следующего дня равен известному среднему
уровню `t`. Это последовательные одношаговые прогнозы без обучения
и подбора параметров. Погода и расход этим baseline не используются.

| Показатель | Результат |
| --- | ---: |
| Горизонт | 1 календарный день |
| Календарных дат оценки | 1 096 |
| Пригодных пар «прогноз — факт» | 994 |
| Исключённых неполных пар | 102 |
| MAE | 5.8255 см |
| RMSE | 8.3349 см |

Средняя абсолютная ошибка на пригодных датах — около **5.8 см**.
Это ориентир для более сложных моделей. Ошибка не характеризует даты
с отсутствующими измерениями: исключение пар может смещать оценку,
если пропуски связаны с паводками или сбоями датчиков.

## Воспроизведение

```powershell
uv sync --locked
uv run --locked river-forecast fetch --config config/suwannee_branford.toml
uv run --locked river-forecast evaluate --config config/suwannee_branford.toml
```

Артефакты: `artifacts/suwannee_branford/metrics.json`, `predictions.csv`,
`quality.json`, `run.json`. При пересмотре USGS или реанализа результат
может измениться: сравнивайте контрольную сумму и исходные снимки.

## Ограничения

Прогнозируется суточный средний уровень по шкале поста, а не мгновенный пик
паводка или абсолютная высота. Метрики описывают ретроспективный расчёт
на исправленной истории при допущении доступности предыдущего уровня.
Фактическое время публикации ещё предстоит учесть.

Пока нет Ridge, XGBoost, подбора параметров и анализа экстремумов.
Этот baseline не заменяет будущую единую временную валидацию.
