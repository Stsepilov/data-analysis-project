# Аннотация проекта

## Тема проекта

Разработка прогнозно-аналитической системы для прогнозирования уровня воды
в реке на основе гидрологических и метеорологических данных.

## Аннотация проекта

Проект посвящён разработке прогнозно-аналитической системы для мониторинга
и прогнозирования уровня воды в реке. Актуальность работы связана с
необходимостью своевременного выявления изменений гидрологической
обстановки и возможного повышения уровня воды под воздействием погодных
факторов.

Цель проекта — создать систему, которая автоматически собирает и объединяет
гидрологические и метеорологические данные, формирует на их основе признаки
и строит прогноз уровня воды на заданный временной горизонт. В качестве
источников данных используются **USGS Water Data API** для получения
информации об уровне и расходе воды и **Open-Meteo API** для получения
данных об осадках, температуре, влажности и других погодных параметрах.

Для обработки данных и построения прогнозных моделей будут использоваться
**Python, Pandas, scikit-learn и XGBoost**. Данные будут храниться в
**PostgreSQL**, результаты экспериментов и метрики моделей — фиксироваться
с помощью **MLflow**, автоматизация загрузки и обработки данных будет
выполняться с использованием **Prefect**, а результаты анализа и
прогнозирования будут представлены в интерактивном дашборде на **Streamlit**.

Ожидаемым результатом проекта является работающий прототип системы,
позволяющий отслеживать динамику уровня воды, получать прогноз и оценивать
качество используемой модели.

## Рабочий объект исследования

Выбран пост **USGS 02320500 — Suwannee River at Branford, Florida, США**.
Начальная задача — прогноз среднего уровня следующих суток. Этот выбор
конкретизирует объект, сохраняя источники и стек исходной аннотации.

Текущая реализация и планируемые компоненты разделены в README и матрице
требований: аннотация описывает ожидаемый итог проекта.
